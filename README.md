### **ЗАУВАЖЕННЯ**

1) Назва класу **Human** має бути написана з великої літери.
2) **HumanIMB** треба перейменувати, щоб з назви було більш зрозуміло, для чого цей клас, наприклад: HumanBodyMassIndex
3) Між 11 і 12 рядком, які розділяють класи **Main** та **HumanIMB**, треба поставити порожній рядок для кращої читабельності.
4) Змінну **W** повинна відповідати camelCase, оскільки не є константою.
5) Змінну **H** повинна відповідати camelCase, оскільки не є константою.
6) Змінну **W** треба перейменувати на weight для зрозумілості. Тоді не буде потреби в коментарі.
7) Змінну **H** треба перейменувати на height для зрозумілості. Тоді не буде потреби в коментарі.
8) Змінну imb треба видалити, оскільки в ній немає потреби (завжди треба використати метод, який повертає поточне значення BMI).
9) Замість змінної imb треба створити метод _public double getBodyMassIndex()_, який повертав би поточне значення індексу маси тіла.
10) Метод **takeW()** треба перейменувати на **getWeight()**, щоб відповідати стандартам найменування.
11) Метод **takeH()** треба перейменувати на **getHeight()**, щоб відповідати стандартам найменування.
12) Метод **putW()** треба перейменувати на **setWeight()**, щоб відповідати стандартам найменування.
13) Метод **putH()** треба перейменувати на **setHeight()**, щоб відповідати стандартам найменування. 
14) Змінну W треба зробити private для інкапсуляції.
15) Змінну H треба зробити private для інкапсуляції.
16) Метод **public static String Result()** треба змінити на **public String getBodyMassIndexDescription()**, який представляв би рівні категорії індексів маси тіла.
17) У методі **getBodyMassIndexDescription()** потрібно для двох умов _(imb >=18.5 & imb <25 та imb >=25 & imb <30) змінити знак & на && для логічних операцій.
18) У методі **getBodyMassIndexDescription()** потрібно додати блоки else-if, щоб не обраховувати кожен з них, якщо ми вже отримали true.
19) У методі **getBodyMassIndexDescription()** краще замінити категорії індексів маси тіла, які повертаються з метода, на категорії, які є наведені в Інтернеті.
20) Між знаками порівняння _(приклад: imb >=18.5)_ та цифрами треба поставити пробіли для кращої читабельності.
21) Для кращої читабельності, можна одразу повертати значення з метода, а не встановлювати значення змінної і лише потім повертати.
22) Для кращої читабельності, можна поставити умову **if (currentBodyMassIndex < 18.5)** на початок.
23) Для значень BMI > 30, блок if не потрібен.
24) Краще винести методи, пов'язані з обрахуванням BMI, в окремий клас. 
    Тоді **Human** матиме відповідальність за збереження **weight** і **height**, 
    а, наприклад, клас **HumanBodyMassIndexCalculator** матиме відповідальність за визначення BMI.
25) Для кращої читабельності треба мати відступи між блоками коду (наприклад, між методами).
